## Evidence rules

- **Handler test** means an isolated Functions contract test exercises that agent's request/prompt/output contract. It does not prove a live provider call.
- **Emulator workflow test** means the exported `handleSession` HTTP handler receives an ID token minted by Firebase Auth Emulator, reads/writes Firestore Emulator, and calls a local fake model endpoint. It proves the tested server path without production authentication, App Check, or paid model traffic.
- **UI/route test** means a local test covers the entry point or Experience Engine payload. It does not prove authentication, App Check, model output, or production behavior.
- **Live verification** is not marked complete for this iteration. The completed release gate is local/emulator evidence only.
- `readiness: implemented` in the shared catalog means a server handler is registered. It does not mean all workflow gates have passed.
