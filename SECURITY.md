# Security Policy

## Supported versions

We support the current main branch and recent tagged releases. Security fixes are prioritized for the latest release.

## Reporting a vulnerability

If you discover a security vulnerability, please report it responsibly:

- **Email**: [security contact placeholder - replace with your email]
- **Do not** open a public issue for security vulnerabilities

### What NOT to include in reports

- API keys, tokens, passwords, or other secrets
- Protected health information (PHI) or patient data
- Full stack traces or logs that may contain sensitive data

## Responsible disclosure

This repository is private. We still follow responsible disclosure practices: we ask reporters to allow reasonable time for remediation before any public disclosure.
