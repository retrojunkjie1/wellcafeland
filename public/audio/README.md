# Audio assets (Phase 56)

Place local audio files here for voice/guidance. Expected filenames:

- **cue_inhale.mp3** — short cue for inhale (<1s)
- **cue_hold.mp3** — short cue for hold (<1s)
- **cue_exhale.mp3** — short cue for exhale (<1s)
- **ambience_soft.mp3** — optional loop (<30s)

If files are missing, the breathing scheduler still runs; cues are no-ops. Phase 56 follow-up: add real calm tones when ready.
